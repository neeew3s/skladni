# Техническая документация сайта "КРЕПОСТЬ"

## Общее описание проекта

Сайт "КРЕПОСТЬ" - это современная веб-платформа для компании, специализирующейся на производстве и продаже систем безопасности военного класса. Проект разработан на Next.js 16 с использованием TypeScript, React и современных UI-компонентов.

### Основные технологии
- **Frontend**: Next.js 16, React 19, TypeScript
- **UI Framework**: Radix UI, Tailwind CSS
- **3D графика**: Three.js, React Three Fiber
- **Анимации**: Framer Motion
- **Формы**: React Hook Form с Zod валидацией
- **Состояние**: React Context API

## Структура сайта

### 1. Главная страница (/)

#### 1.1 Навигационная панель (Navbar)
- **Логотип**: "КРЕПОСТЬ" с иконкой щита
- **Навигационные ссылки**:
  - "ПРОДУКЦИЯ" - плавная прокрутка к секции товаров
  - "ИНЖЕНЕРИЯ" - переход к 3D визуализации
  - "ХАРАКТЕРИСТИКИ" - прокрутка к форме консультации
- **Корзина**: 
  - Отображение количества товаров
  - Анимированный индикатор при наличии товаров
  - Переход на страницу корзины (/cart)
- **Мобильное меню**: выдвижная панель для мобильных устройств

#### 1.2 Hero-секция
- **Заголовок**: "ЗАЩИТИТЕ СВОЕ имущество" с градиентным эффектом
- **Описание**: Передовые бронированные ставни, модульные контейнеры и жилые бункеры
- **Кнопки действий**:
  - "Конфигуратор" - переход к настройке продукции
  - "Каталог" - переход на страницу каталога (/catalog)
- **Преимущества**:
  - Баллистическая защита (NIJ Level IV)
  - ЭМИ экранирование (клетка Фарадея)
  - Биометрический доступ (сканирование сетчатки)

#### 1.3 Инженерная секция (3D визуализация)
- **Выбор модели**: Бункер, Контейнер, Ставни
- **Режимы просмотра**:
  - Стандартный вид
  - Взрывной вид (показ слоев)
  - Секционный вид (разрез)
- **Управление состоянием**:
  - Открыто/Закрыто
  - Метки деталей (включение/выключение)
- **Интерактивные элементы**:
  - Наведение на части модели показывает спецификации
  - Анимированные переходы между состояниями
- **Техническая информация**:
  - Координаты объекта
  - Статус системы
  - Уровень защиты

#### 1.4 Секция продукции
- **Заголовок**: "ЛИНЕЙКА ПРОДУКЦИИ"
- **Фильтрация по категориям**: Жилой, Модульный, Бункер, Промышленный, Военный
- **Карточки товаров**:
  - Изображение товара
  - Категория
  - Название и цена
  - Краткое описание
  - Кнопка "Конфигурация"
- **Ссылка на полный каталог**

#### 1.5 Призыв к действию
- **Заголовок**: "ГОТОВЫ К УКРЕПЛЕНИЮ?"
- **Описание**: Консультация с инженерами по безопасности
- **Кнопки**:
  - "ЗАПИСАТЬСЯ НА КОНСУЛЬТАЦИЮ" - открытие формы
  - "СКАЧАТЬ СПЕЦИФИКАЦИИ" - доступ к документации

#### 1.6 Форма консультации
- **Поля формы**:
  - ФИО
  - Номер телефона (автоформатирование +7(XXX)-XXX-XX-XX)
  - Город
  - Намерения (текстовое описание)
- **Валидация**: обязательные поля
- **Успешное отправление**: модальное окно с подтверждением

## Функциональные возможности

### 1. Управление состоянием

- **Корзина**: добавление, удаление, изменение количества

- **Дизайн**: настройка визуальных параметров

### 2. 3D визуализация
- **Three.js**: рендеринг 3D моделей
- **Интерактивность**: вращение, масштабирование, выбор частей
- **Анимации**: плавные переходы между состояниями
- **Мобильная оптимизация**: адаптация для мобильных устройств

### 3. Формы и валидация
- **React Hook Form**: управление формами
- **Zod**: схема валидации
- **Автоформатирование**: телефонных номеров
- **Обработка ошибок**: пользовательские сообщения

### 4. Адаптивный дизайн
- **Мобильная версия**: оптимизация для экранов < 768px
- **Планшетная версия**: адаптация для средних экранов
- **Десктопная версия**: полный функционал

### 5. Производительность
- **Lazy loading**: подгрузка компонентов по необходимости
- **Оптимизация изображений**: Next.js Image
- **Кэширование**: localStorage для данных
- **Минимизация re-renders**: оптимизация React компонентов
